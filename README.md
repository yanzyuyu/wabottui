# 🤖 Bot WhatsApp OpenCode v2.0 (200+ Fitur & Live Auto-Sync)

Bot WhatsApp modern berbasis Node.js & Baileys v6.7 dengan integrasi Groq AI (Llama 3.3 70B), Downloader Suite Lengkap, Web Pentest Tools, Image Processing Effects, Finance & Crypto Realtime, dan Live Auto-Sync via Nodemon.

## 🔄 Fitur Otomatisasi: Live Auto-Sync (Hot Reload)

Bot ini telah dilengkapi **Nodemon Watcher**. Setiap kali Anda mengubah atau menambah kode di file `index.js` atau file project lainnya, **bot akan otomatis restart dan menyesuaikan (sync) secara realtime** tanpa perlu Anda matikan terminal manual!

```bash
npm start   # atau npm run dev
```
